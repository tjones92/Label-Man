# Pre-registration amendment 3 — diagnostic method clarifications

The bounded pair analyzer uses hash-seeded xorshift sampling of unique unordered pairs, then hashes their order. It does not select the globally lowest 2,000 hashes from the full Cartesian product. This reduces analysis memory; the sample count, seeds, thresholds and deterministic comparison across variants are unchanged. This implementation difference is disclosed, not fitted to outcomes.

The production widget's fit bands are continuous uncertainty intervals. Five equal-width bins of the actual capability, identity and moment values are descriptive report bins, not gameplay thresholds.

Source inspection identified full recording dates and artist IDs in `SongMasterMetadata`, exposed through `PolarSongMetadataService.Masters`. Append an act-specific D3 cap to the existing labelled shared-year proxy: the last 12 master records by year/month/day descending, stable master ID tie-break. Retain the proxy as a separately named comparison. Both filters apply to the candidate pool before bucket ranking; this is broader than removing only first-bucket entries while allowing them to return in later buckets. No production admission changes.

Export the 350 D2 prototype values to demonstrate the finite-mixture difference in the partial 175-clone dose. The x2 and x3 pools duplicate the mixture exactly. These are diagnostic output changes; the already completed shape-only trajectories are unaffected. Historical proposals and shape values remain unchanged.
