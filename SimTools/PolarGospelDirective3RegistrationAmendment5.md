# Pre-registration amendment 5 — pair-sample reproduction key

Key the bounded pair sample by development seed, observation stage and source/archetype group rather than the artifact run name. This ensures a fresh-name replay of identical compositions has identical analysis samples. The same pairs are used for legacy, v1 and v2. The source of variation, sample count, sampling algorithm and all proposed thresholds are unchanged. This corrects a reproduction dependency on filenames; no threshold or offset is selected from its results.
